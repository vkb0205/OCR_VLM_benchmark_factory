# Architecture

A seeded spec selects report variables and pooled prose. The element agent schedules company and statement groups concurrently, followed by dependent chart and note-table groups. Each group has a separate repair conversation; merged content passes the full financial validation rules.

The design agent receives inventory, deterministic draws, a design ledger, and the slot contract. It returns a blank HTML design and design spec. The renderer fills slots from validated content. Contract lint and design checks feed repairs, including rendered contact sheets. Accepted designs are recorded in the ledger; failed attempts retain their traces.

The CLI writes document bundles and galleries. Export uses the ported OmniDocBench builder and selects only bundles marked as agent designs. The bilingual balance layer is under construction; see `todo.md` for unverified requirements.
