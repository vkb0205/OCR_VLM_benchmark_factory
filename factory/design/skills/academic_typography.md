# Academic typography

Set a clear hierarchy with a restrained number of sizes and weights. The body size declared in `layout_plan` is the minimum reference for prose; never set any visible text run below 8 pt, including nested math, table cells, captions, and notes. Use line height that supports long reading and Vietnamese accents without wasting the page. Keep measure comfortable for the region width and avoid dense all-caps paragraphs.

Use the selected registry families by name through `--font-head` and `--font-body`. Assign roles deliberately: display emphasis belongs in short labels or titles, while long passages need a steady text face. Distinguish title, section, subsection, caption, note, and running matter through scale, weight, spacing, and alignment rather than decoration alone. Keep figures and captions visually connected, and preserve consistent rules for references and equations.

Check the rendered title page, body page, and references page. Use `measure` when spacing or fit is uncertain. Correct the cause of crowding before adding ornament.
