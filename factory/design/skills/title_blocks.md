# Title blocks

The title page must accommodate the title, authors, affiliations, abstract, optional alternate-language abstract and keywords, optional journal label, and optional acknowledgement. The code places each field exactly once. Style the hierarchy and spacing; do not add, remove, or duplicate text.

Use the profile's character lengths and counts to reserve enough space for the longest title, author line, and affiliation. Keep author-to-affiliation relationships legible. Make the abstract and keywords easy to locate and give the title page a clear entry point into the paper. Avoid fixed heights on text blocks and keep all content inside the declared title-page regions.
